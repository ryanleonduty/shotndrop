# ShotNDrop v0.1.2 — Smoother shelf dragging

## Install

1. Download `ShotNDrop-0.1.2.dmg` from the release assets.
2. Drag `ShotNDrop.app` into `/Applications`.
3. First launch: right-click the app → **Open** → **Open**. macOS warns "unidentified developer" because the build is unsigned.

Requires macOS 14+ (Sonoma).

## What's in this build

- Shelf dragging stays attached to the cursor without cumulative fractional-coordinate drift.
- Dragging an expanded shelf between displays recalculates its height for the destination display.
- Expanded and minimized shelf positions remain visible while dragging.
- ESC collapses the expanded shelf and releases keyboard focus.
- Improved contrast for transient drop, acquired, and rejection states.

## Known limits

- Unsigned build. Expect the one-time Gatekeeper warning on first launch.
- No auto-updater. Watch the repository or check Releases for new versions.
- Session-only storage: quitting clears the shelf.
