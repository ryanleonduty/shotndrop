# ShotNDrop v0.1.3 — Update checking and menu polish

## Install

1. Download `ShotNDrop-0.1.3.dmg` from the release assets.
2. Drag `ShotNDrop.app` into `/Applications`.
3. First launch: right-click the app → **Open** → **Open**. macOS warns "unidentified developer" because the build is unsigned.

Requires macOS 14+ (Sonoma).

## What's in this build

- Added **Check for Updates** to the menu bar and shelf menus.
- Update checks compare the installed version with the latest GitHub release.
- Added relevant menu icons for Clear, Check for Updates, and Quit.
- Update alerts are modeless so the shelf remains usable while an alert is open.

## Known limits

- Unsigned build. Expect the one-time Gatekeeper warning on first launch.
- Updates are checked manually and downloaded from GitHub; the app does not install updates automatically.
- Session-only storage: quitting clears the shelf.
